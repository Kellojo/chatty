# Source quality ranking

When choosing sources for research, prefer in this order:

1. **Primary sources** — official documentation, original papers, RFCs, legal texts, source code, official announcements.
2. **Primary reporting** — journalists or analysts citing named sources and data; the outlet has editorial standards.
3. **Vendor/project pages** — accurate about their own product's features, but treat comparative or performance claims as marketing.
4. **Community consensus** — Stack Overflow accepted answers, GitHub issues/PRs, maintainer comments. Good for practical gotchas; verify version relevance.
5. **Aggregators / SEO content / forums without citations** — use only to discover leads, never cite directly.

## Red flags

- No publication date, or date far outside the topic's relevance window.
- Claims with no named source or data.
- Content that restates another page's content without adding anything.
- AI-generated content farms (generic phrasing, no specifics, no authors).

## Version sensitivity

For software topics, always note which version a source describes and prefer sources matching the version in question.
